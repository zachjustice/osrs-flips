# OSRS Flip Recommendations

A static, hourly list of Old School RuneScape Grand Exchange flip
candidates, published at <https://zachjustice.github.io/osrs-flips/>.

This repository contains only the public website assets and the displayed
recommendation data in [`data/flips.json`](data/flips.json). The private model
publishes a new data-only commit after each successful, non-empty run.

Estimated profit/hour uses the model's expected profit and expected slot time.
Max profit is the theoretical after-tax unit margin multiplied by the full
Grand Exchange buy limit. Prices, fills, and actual returns can differ. Check
every trade before placing an offer; losses are possible.
