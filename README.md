# OSRS Flip Shortlist

A static, hourly shortlist of Old School RuneScape Grand Exchange flip
candidates, published at <https://zachjustice.github.io/osrs-flips/>.

This repository contains only the public website assets and the displayed
recommendation data in [`data/flips.json`](data/flips.json). The private model
publishes a new data-only commit after each successful, non-empty run of its
240-minute tier.

The displayed gold/hour figure is the theoretical after-tax unit margin
multiplied by the full four-hour Grand Exchange buy limit and divided by four
hours. Prices, fills, and actual returns can differ. Check every trade before
placing an offer; losses are possible.
